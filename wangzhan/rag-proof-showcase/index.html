02 搭建结构

RAG 搭建结构

原型没有依赖外部向量数据库，使用项目内文件完成语料存储、向量化、相似度召回和结果展示。

核心文件路径

server/data/corpus.json server/data/vectordb.json 后端知识库服务模块 后端检索接口模块

状态接口样例

知识库状态：已完成
原始知识文档：100 条
向量索引条目：100 条
覆盖名马数量：100 个
默认召回数量：3 条
资料整理梳理历史记载、演义文学、评书传统和名马文化条目。
结构化录入统一写入 id、text、metadata、source、labels 等字段。
构建索引通过 build_vectordb 生成本地向量检索文件。
相似度召回query_vectordb 根据用户问题返回相关片段。
结果展示将命中片段返回页面，用于资料展示和内容引用。

03 视频工厂层

视频工厂专用素材层

为了让视频工厂生成更好的脚本、分镜、关键帧和 Veo 提示词，项目新增了一层独立素材库。它不替换原有 RAG 语料，因此不会影响聊天助手、推荐和其他知识问答功能。

独立文件路径

server/data/corpus.json server/data/vectordb.json server/data/video_factory_rag.json server/app/services/workflow_tasks.py

聊天功能继续读取原始 `corpus.json` 与 `vectordb.json`；视频工厂会先读取 `video_factory_rag.json`，没有命中时才回退到原始知识库。

面向视频生成的字段

hook 开场钩子 conflict 冲突 emotional_arc 情绪弧线 visual_keywords 画面关键词 shot_beats 分镜节拍 video_angles 选题角度 prompt_guidance 提示词约束 avoid 负向约束

赤兔样例

开场钩子：
一匹马两任主人，却把三国最锋利的野心和最沉重的忠义都驮在背上。

视觉关键词：
赤色鬃毛、铁蹄火星、青龙偃月刀、战旗、月下回望、尘土冲锋

分镜节拍：
红影掠过战场 -> 吕布剪影压住前景 -> 马缰易手 -> 关羽与赤兔并肩

调用边界

视频工厂：
topic + horse + brief
  -> video_factory_rag.json
  -> promptSeed / ragReferences / nextPrompt
  -> 分镜、关键帧、Veo 提示词

聊天助手：
用户问题
  -> corpus.json / vectordb.json
  -> sources / matched_horse
  -> 聊天回复

06 录入说明

首批史料录入说明

百骑谱项目已完成 RAG 知识库原型搭建。首批录入 100 条历史名马及传统名驹资料，覆盖史籍记载、古典文学、评书传统、民间演义与名马文化意象。每条资料均包含名马名称、关联人物、来源标注、故事摘要和人格标签，并通过本地向量索引接入资料检索流程。该原型可为名马知识整理、用户查询、文创商品资料关联和视频脚本素材整理提供基础知识支撑。
