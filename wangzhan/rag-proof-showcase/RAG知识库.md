# 首批历史名马史料录入说明

## 一、录入目的

百骑谱项目围绕中国历史名马、文学名马和传统名驹展开。项目里会反复用到这些资料，例如名马故事展示、人物关系说明、文创商品资料整理，以及后续视频脚本素材组织。为了避免这些内容散落在页面文案、脚本草稿和临时备注里，本次先整理了一批基础资料，作为 RAG 知识库的第一版语料。

这批资料不是最终全量库，而是一个可核验的首批版本。它的重点是先把名马名称、关联人物、出处类型、故事摘要和标签整理成固定格式，后面再逐步补充更细的出处版本和扩展字段。

## 二、录入数量

首批共录入 **100 条历史名马及传统名驹资料**。

目前对应两个数据文件：

- `server/data/corpus.json`：保存整理后的原始语料。
- `server/data/vectordb.json`：保存由原始语料生成的本地检索索引。

两个文件中的条目数量一致，都是 100 条。也就是说，目前录入的首批资料已经完成了从原始文本到检索索引的基础处理。

另外，视频工厂新增了一份独立素材层：

- `server/data/video_factory_rag.json`：保存面向脚本、分镜、关键帧和 Veo 提示词的增强素材。

这份素材层目前包含 **18 条核心名马视频素材**，不会替换 `corpus.json`，也不会改变聊天助手使用的默认知识库。视频工厂会优先读取这份素材层；如果没有命中，再回退到原始知识库。

## 三、资料覆盖范围

本次没有只收录严格意义上的正史名马，而是按照“百骑谱”的项目定位，把历史记载、演义文学、评书传统和民间名马意象都纳入了首批资料中。这样处理更符合名马文化本身的传播方式，也更适合后续做故事展示和内容创作。

首批资料主要包括以下几类：

- 历史或史籍相关名马，例如赤兔、乌骓、的卢、绝影等。
- 古典文学和演义系统中的名马，例如《三国演义》《说唐》等文本或传统中的坐骑形象。
- 评书、戏曲和民间演义中常见的名驹，例如带有固定人物绑定或鲜明气质设定的马名。
- 古典名马传统中的文化条目，例如昭陵六骏、穆天子八骏和古代名驹命名传统。
- 为项目内容整理所需的气质标签，例如忠义、孤勇、转机、速度、护主、沉稳、祥瑞等。

其中，史籍、文学演义和民间传统的性质不同，所以每条资料都保留了 `source` 字段，用来说明该条资料来自哪类叙事或文化系统。

## 四、来源处理方式

名马资料有一个特点：很多名字既出现在历史叙事中，也经过文学、戏曲、评书和民间传说不断加工。比如赤兔既有历史名马的基础认知，也有《三国演义》中非常强的文学形象；照夜玉狮子、黄骠马、呼雷豹这类名称，则更偏向演义、评书或民间传统中的人物坐骑意象。

因此，本次录入没有把所有条目都写成“正史记载”。更稳妥的做法是把来源写清楚：属于史籍相关的就标注史籍或时代背景，属于演义、评书、戏曲系统的就标注对应传统。这样既保留了文化内容的丰富性，也避免把不同性质的资料混为一谈。

后续如果继续扩展，可以在 `source` 字段之外再增加更细的字段，例如具体书名、章节、版本、可信度等级等。

## 五、字段结构

首批资料统一写入 `corpus.json`。每条资料由一个编号、一个完整文本和一组结构化信息组成。

示例：

```json
{
  "id": "horse-001",
  "text": "赤兔。对应人物：吕布、关羽。朝代/出处：东汉末年《三国志》/《三国演义》。故事：先从吕布，后归关羽，是三国最具辨识度的名马之一。人格标签：忠义、速度、锋芒。",
  "metadata": {
    "sequence": 1,
    "name": "赤兔",
    "figure": "吕布、关羽",
    "source": "东汉末年《三国志》/《三国演义》",
    "story": "先从吕布，后归关羽，是三国最具辨识度的名马之一",
    "labels": ["忠义", "速度", "锋芒"]
  }
}
```

主要字段说明：

- `id`：条目编号，方便检索和定位。
- `text`：用于检索的完整文本，把名称、人物、出处、故事和标签合在一起。
- `metadata.sequence`：录入序号。
- `metadata.name`：名马名称。
- `metadata.figure`：关联人物或文化形象。
- `metadata.source`：来源标注，用来区分史籍、演义、评书、民间传统等类型。
- `metadata.story`：故事摘要，保留该名马最容易被识别的文化记忆点。
- `metadata.labels`：标签，用来概括名马气质和故事主题。

视频工厂专用素材层在这些基础字段之外，增加了更适合生成画面和提示词的字段：

- `metadata.hook`：短视频开场钩子。
- `metadata.conflict`：故事冲突或情绪张力。
- `metadata.emotional_arc`：视频情绪推进线。
- `metadata.visual_keywords`：关键画面元素。
- `metadata.shot_beats`：可直接拆成分镜的节拍。
- `metadata.video_angles`：可选的视频选题角度。
- `metadata.prompt_guidance`：给后续图片/视频模型的提示词方向。
- `metadata.avoid`：负向约束，避免拍偏或混淆史料与原创设定。

## 七、标签整理

标签是这批资料中比较重要的一部分。录入时没有追求标签数量很多，而是给每条资料保留 2 到 3 个最能代表它的词。

标签大致分为几类：

- 精神气质：忠义、孤勇、护主、义气、悲壮等。
- 行动特征：速度、爆发、迅捷、耐战、执行等。
- 情绪和视觉印象：沉稳、冷峻、清贵、祥瑞、神秘等。
- 文化意象：白马英雄、名将气、权势、天命、转机等。

这样做的好处是，资料不只可以按名称检索，也可以按故事主题和气质检索。例如用户想找“逆境”“转机”“忠义”相关的名马，就可以通过标签和故事摘要找到更贴近的条目。

## 八、录入流程

首批资料的整理过程比较直接：

1. 先列出项目需要覆盖的历史名马和传统名驹名称。
2. 为每个名称补充关联人物或对应文化形象。
3. 标注来源类型，尽量区分史籍、演义、评书和民间传统。
4. 将故事压缩成一两句话，保留最核心的信息。
5. 给每条资料补充 2 到 3 个标签。
6. 按统一格式写入 `corpus.json`。
7. 基于 `corpus.json` 生成 `vectordb.json`，用于本地检索。

这套流程的目标不是一次性写成百科全书，而是先把资料整理成项目可以继续使用和扩展的格式。

## 十、当前版本边界

这批资料是项目早期版本，已经可以证明知识库原型和首批录入工作完成，但还不是最终精校版。当前版本主要做了名称、人物、来源类型、故事摘要和标签整理。

后续如果继续打磨，可以补充更细的出处信息，例如具体篇章、不同版本出处、朝代地域、马主人、战役场景、可信度标记等。这样可以让资料库从“可用的首批语料”逐步变成更完整的名马文化资料库。

## 十一、结论

本次首批历史名马史料录入已经完成。当前知识库包含 100 条结构化语料和 100 条对应检索索引，能够展示百骑谱项目在历史名马资料整理方面的第一阶段成果。

这批资料的价值在于，它把原本零散的名马故事整理成了可检索、可扩展、可引用的数据格式。后续无论是继续补充史料，还是用于页面展示、推荐逻辑和视频脚本素材整理，都可以在这批资料的基础上继续推进。
