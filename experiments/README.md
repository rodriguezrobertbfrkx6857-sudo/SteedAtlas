# 离线探索性实验

运行：`.venv/Scripts/python.exe experiments/run_benchmarks.py`。

数据来自已保留的 100 条 corpus；精确查询的 gold 由原记录 ID 派生，不是双人独立史料标注。别名与无答案题为人工编写的合成 POC。
调度实验只运行确定性规则控制器，不调用 LLM，不报告语言质量、token 或人工修订收益。
恢复对照 R2+ 包含与 R3 相同的知识版本/状态/元数据及保守语义失效规则；不故意削弱强基线。对照使用合成变更，不代表真实编辑分布。
指标为实际运行脚本输出；未测项目保持 null。不会凭零故障样例声称严格 exactly-once。
