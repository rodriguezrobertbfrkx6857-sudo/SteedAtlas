# 新视频工厂：不用视频模型也能从知识到成片

## 一条可用链路
`CreateProject → SelectHorse/Topic → GatherEvidence(optional) → ScriptEditor → ScriptReview → Storyboard/SceneBible → [VisualAssetBranch || NarrationAudioBranch] → DurationResolve → SubtitleAlign → CanonicalTimeline → Preview → FFmpegRender → QA → Publish/Download`

## 两类运行模式
- **Guided**：选择名马/主题/比例/长短 → 上传或选模板 → 编辑剧本 → 自动建立分镜卡片 → 上传音频/视频素材 → 一键合成（必要时提示问题）。
- **Expert**：逐段调场景、分镜顺序、轨道、关键帧动画、字幕层、任务 DAG、Agent Proposal、历史版本和审稿记录。
同一 Creative Project、同一 Timeline、同一后端；不同的只是 UI 投影。

## 不可颠倒的逻辑顺序
1. 剧本、证据选择及故事定位先锁定 Revision，避免“素材生成后突然改变全部叙事”。
2. Director 建立 ScenePlan，指定目标镜头顺序、文字、时长估计、素材需求。
3. 可并行：视觉素材（用户视频/图像/模板，外部生成可选）与旁白音频（上传/既有 TTS/静音）。
4. 最终音频确定后生成 ASR/TTS alignment 或人工时间标注；**字幕不得依据未生成的音频声称已经精准对齐**。
5. 统一决定镜头时间（真实素材时长、旁白时长、人工锁定时长之间的优先规则，超出需要审核）。
6. Timeline 可视化编辑，构建可复现的 RenderPlan，经过 FFmpeg 渲染，自动技术校验。
7. 版权、事实标签、发布审核后输出最终作品；导出不代表自动发布。

## Scene Bible（三层）
- `GlobalBible`：名马身份、时代、角色、文化类别、视觉风格、术语、禁止偏离的来源约束。
- `SceneState`：该场景的地点、时间、角色、事件状态、画面素材和字幕。
- `ContinuityConstraint`：相邻/跨场景一致性约束（时间线、人物、道具、色调、故事因果）；冲突返回可定位的 Finding。
- V1 检查结构化内容与文字，不宣称已能自动识别任何真实视频画面；视觉多模态检查可后续选配。

## 视觉素材优先级
1. 上传/已有可用素材（版权与文件检测必须通过）。
2. 静态图片 + CPU 平移缩放/Ken Burns/转场/字幕，形成合法可播放 MP4。
3. 可选授权外部生成素材（不是必经节点，不准在用户不知情下花钱）。
素材缺失时：提供具体需求清单、选择简易模板或人工上传；不要返回 `mock://` 地址当成生成成功。

## 有声/无声两种流程
- 有声：NarrationText → AudioAsset → real duration/word alignment → SubtitleCues → Timeline。
- 无声：ScriptText + SceneDuration → TimedText → Timeline；界面明确显示“按场景时间分布字幕”，不称“语音对齐”。
- 可选 TTS：现有 API/库明确配置且用户授权后调用；无配置时可上传音频或无声出片。

## 场景级修改与修复
- 删掉素材只会影响相关 Scene/Timeline，不会删除整个工程；采用 tombstone + references 检查。
- 修改场景 subtitle cue，只修改字幕层和所涉及 render segment；原始视频/图片不重做。
- 修改 narrative audio，字幕 alignment 和可能的 scene duration 均可能失效，禁止只替换音频却忽略字幕时轴。
- 修改源 claim 版本，Scene 标为 `NEEDS_REVIEW`; 若相关视觉/叙事是否受影响无法证实，则保守要求人工确认。
- 不要让修复 Agent 直接反复重新生成整个项目；每次修复有 `affected_nodes`, `reason_codes` 和预算上限。

## 真正的出片验收
- 无 API Key、无 GPU、断网状态下，使用 3 张图片+上传音频（或无声）+字幕生成 MP4；可由 ffprobe 读取，宽高/时长在可接受范围。
- 每个 Scene 可复用原有素材；保存刷新不丢失顺序/时间轴。
- 成品包含对应 SRT、渲染配置/素材 hash 与审稿状态；下载要真的能拿到字节。
- 破损音频、无可用素材、错误编解码器需显示明确异常和修复建议，不能标记导出成功。
