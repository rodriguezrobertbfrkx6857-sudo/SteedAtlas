# 自动化测试与端到端验收矩阵

## 基础测试层
- Python: ruff/格式化/pytest/类型检查（按现有工具兼容）；数据库迁移 + 测试事务回滚。
- 前端: TypeScript typecheck、lint、组件测试/DOM、Playwright 浏览器真实交互。
- 安全: 权限、SSRF、上传大小/类型、路径遍历、重复提交、版本冲突、敏感日志。
- 媒体: 固定授权素材，用 ffprobe 解码、时长/FPS/码率/音轨/字幕与错误路径。
- Agent: 工具权限/无授权变更拒绝、Proposal schema、规则调度与版本冲突、`LIVE` vs `MOCK` 标识。
- Runtime: DAG 无环、跨节点依赖、并发租约、崩溃恢复、重复事件/回调、取消、缺失资产、过期审批。

## 高优先级测试用例
| ID | 输入/故障 | 必须观察到的结果 |
| --- | --- | --- |
| SEC-01 | 非管理员 `POST /ai/build` 或非法 out_path | 拒绝；无任意文件写入 |
| SEC-02 | 普通用户更新 RAG 档案 | 拒绝并有审计 |
| SEC-03 | media URL 指向 localhost/metadata | 导入失败，禁止 SSRF |
| KB-01 | 赤兔相关史实/小说来源 | 明确区别并可打开精确 passage |
| KB-02 | 旧版 claim 被撤回 | 所有关联创作内容标注需要复核 |
| AG-01 | 已有完整剧本，资料充分 | 跳过不需要的角色，trace 有 reason codes |
| AG-02 | Agent 版本过时的 Proposal | 409/拒绝；不覆盖用户更新 |
| AG-03 | Agent 连续失败或循环 | 达到上限人工接管，资源不失控 |
| AG-04 | 无 Provider Key | 正确显示 MANUAL/RULE_BASED，非伪 LIVE |
| VID-01 | 三张图片+音频+字幕 | 产出真实可播放 MP4 和 SRT，ffprobe 通过 |
| VID-02 | 中文字幕、无声、竖屏 | 字体/时轴/分辨率正确 |
| VID-03 | 错误视频/音频文件 | `INVALID_OUTPUT`，不生成伪下载链接 |
| TIM-01 | 时间轴拖拽后保存刷新 | 完整恢复，同一 Canonical Timeline 版本 |
| DAG-01 | 前端提交循环节点连接 | 编译器拒绝，并提供错误原因 |
| DAG-02 | 两 Worker 同时抢节点 | 唯一合法 lease、旧 Worker 不覆盖 |
| DAG-03 | 提交/渲染中崩溃后重启 | 已完成产物保留，任务安全恢复或明确未知 |
| DAG-04 | 字幕变化不影响其他原素材 | 只失效必要下游任务；最终成片一致 |
| DAG-05 | Claim 争议标签变化 | 进入复审，不错误复用为史实 |
| UX-01 | 首页→名马→创作→成片 | 真实后端调用、无断链和假成功 |
| UX-02 | 320px 宽度/键盘/无障碍 | 核心流程可用；拖拽有替代方式 |
| REG-01 | 旧收藏、抽卡等历史业务 | 关键旧页面/接口回归，不无故删除 |

## 对模拟测试的界限
- `MockProvider` 用于验证 DAG 与接口语义；只有真实 FFmpeg MP4 才能证明视频工厂可导出。
- 模拟多 Agent 响应不能证明真实 LLM 多角色协作效果；若未授权 API，则记录 Agent 功能仅通过 Schema/Rules/Mocks 验证。
- 导出“文件存在”不等于可播放；必须 probe+decode+download 验证。

## 运行证据要求
每个 Gate 输出真实测试命令、版本、通过数/失败数/跳过原因、stderr、最少一组可复现输入与验证方法。CI 不需要访问私有第三方凭据即可测试绝大多数功能。截图/视频/日志仅保存于被授权项目范围；不要泄露用户私人资料。
