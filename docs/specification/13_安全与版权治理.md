# 安全、隐私、版权及发布治理（G0 的 P0 项优先）

## P0 安全问题与测试
- `app/routers/ai.py` 的构建接口在局部代码未见认证且允许用户给 `out_path`：先审查挂载层权限，再实现身份/角色校验、固定索引目录、路径规范化与白名单；无管理员角色不能触发索引写入。
- 名马档案 RAG 更新接口只有 `get_current_user` 可见：审查是否存在全局 RBAC；否则 curator/admin 才允许修改，发布审核可分离。
- 默认 `DEBUG=True` 和开发 `SECRET_KEY`：生产配置启动时拒绝弱密钥和 debug，禁止把密钥写入 git/报告/日志。
- 上传与路径：白名单格式、魔数识别、体积限制、媒体解码隔离、随机/内容寻址存储；禁止用户控制服务器输出绝对路径。
- URL 导入和媒体代理：阻止访问 localhost、私网、云元数据 IP、恶意重定向和任意端口；适配外部代理 SSRF 检测。
- Workflow YAML/JSON：节点 schema、依赖无环、工具与最大资源限制；禁止把用户参数拼入 shell 命令。
- 隐私与鉴权：Project、Job、Asset、Trace、Admin/Review 每个 API 检查 owner/role。下载默认私有，禁止直接公开 generated 目录。

## 数据安全
- 日志不得记录 API keys、callback token、签名 URL、完整私有文件路径、敏感上传文本；密钥只从环境变量/密钥存储读取。
- Agent 输出/检索资料不可信：引用不能驱动工具调用，Prompt Injection 作为 P0 测试样例。
- 漏洞修复保留回归测试。任何安全测试必须在被授权的本地/测试环境，不主动扫描真实线上第三方系统。
- 数据库迁移前备份，写入事务、审计日志、权限检查、发布/删除批准记录。

## 版权及作品来源
- Source/Passage 记录原始版本、授权情况、可引用范围。历史事件不等于具体扫描文献/现代译本无版权。
- 每个图片/视频/音频/字体 Asset 带 `rights_status`, `license`, `attribution`, `uploaded_by`，权利未明时不得自动公开发布。
- AI 生成内容必须保留 provenance 和风险标签；可选外部 provider 的使用条款、生成内容归属与地域限制需单独核查。
- 不未经授权克隆真实人物的声音或使用受限音乐素材。
- 用户手动保存草稿与作品发布是不同权限和 Gate；发布前检查事实、版权和可访问性。

## 生产安全验收
- 未登录触发后台写接口：403/401；普通用户改他人项目：403/404；路径遍历/SSRF/大文件/恶意媒体：明确拒绝并记录审计。
- 开发默认密钥在 production profile 下启动失败；API 运行无敏感信息泄漏；重要路径具备 rate-limit 和配额。
- 从备份可恢复，账户、素材、创作工程和权限一致。
