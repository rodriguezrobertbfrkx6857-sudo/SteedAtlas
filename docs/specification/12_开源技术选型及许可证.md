## 本轮明确不作为必需依赖
ComfyUI、Wan、LTX、HunyuanVideo、MiniMax 视频模型、微调/训练框架、GPU 推理集群。Remotion 有非标准的商业许可，不应把 Source-Available 当作无条件开源。n8n 不是对所有商业模式都可自由嵌入的 MIT 库，已存在的 webhooks 需保留兼容但不是系统内核。

## 逐项目 POC 评分（记录事实，不用主观分数决定一切）
1. 功能适配：是否提供实际需要的编辑/拖拽/预览/操作；有无最小复现。
2. 兼容性：现有 React/TS 版本、后端接口、打包器、CSS 冲突、SSR/浏览器问题。
3. 运行与性能：普通 CPU 预览/渲染耗时、内存峰值、并发、错误率。
4. 可维护：源码结构、测试、API 稳定、维护周期及问题清单。
5. License Gate：每个库本体及关键依赖是否能在私人/商业网站合法使用，GPL/AGPL 网络服务、NOTICE/字体/素材/模型权重分别检查。
6. 替换性：是否有 Adapter、是否锁死业务模型、能否移除不破坏历史项目数据。

## 应优先实现的三个 POC
- **React Flow POC**：3 个场景内容图 + 6 个执行节点，支持边校验、重新加载、无环、屏幕阅读器可访问的列表镜像。
- **Tiptap POC**：中文段落与 `claim_revision_id` 注释锚点，改写局部段落后引用不丢失；可导出普通文本和结构化 JSON。
- **Timeline POC**：三轨（图像/音频/字幕）100% 往返保存，毫秒/帧转换准确，对现有 FFmpeg 能输出正确结果。Rendiv 作为可选 A/B，不做首轮强依赖。

## 许可证交付
生成 `THIRD_PARTY_NOTICES.md`，包含：项目名、实际 pinned 版本/commit、原仓库、SPDX 许可证、直接复用文件/代码的来源、是否修改、附加 NOTICE、字体/图片素材许可证、媒体供应商条款、分发方式和审查结果。不能靠 GitHub Star 数替代许可或质量证据。

## 允许参照，但不允许盲信
项目 README 中“支持自动成片/完全自动/AI Agent”属于项目方声明；是否真的满足百骑谱的用户流，需要本地 POC、API/渲染输出和版权审查。任何库的最新版本需在 Sol 执行时重新查询官方发布记录、固定版本后才依赖。
