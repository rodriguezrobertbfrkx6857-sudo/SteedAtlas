# 产品范围、非目标和真实完成定义

## 定位与四类人
- **访问者**：浏览名马图鉴、年代和人物背景、来源、文化内容；问有引用的中文问题。
- **创作者**：从某匹马进入创作工程，编辑剧本、分镜、上传素材、调整时间轴、真实导出作品。
- **审核者/管理员**：审核史料、争议标签、作品发布、权限和素材使用条款。
- **研究者/开发者**：从 Expert 工作台观察 DAG、执行轨迹、来源依赖与测试对照。

## 产品信息架构
首页 → 名马图鉴/搜索 → 名马详情 → [史料/问答/创作] → 创作项目（引导/专家） → 剧本/分镜/素材/时间轴 → 预览与导出；用户中心 → 我的作品与收藏；管理员 → 史料、审稿与权限。原有抽卡、性格/收藏、文创相关页面不随意删除；对不可用的商业流程明确显示状态。

## 六个正式场景（构成产品验收）
1. 未登录访问者从首页打开赤兔档案，浏览已审核来源，点击精确引用，能区分文学与史实。
2. 用户检索别名和跨字段关键词；对缺乏可靠证据的问题获得明确的证据不足提示。
3. 创作者选择名马，编写/编辑 3 场景剧本，保存刷新后不丢失；审查与版本记录可查看。
4. 创作者上传本地图片/音频/视频，或用已有图文模板，调整时间轴、字幕/镜头时长，在无视频模型且无外部 LLM 的情况下导出**真实可播放 MP4**及 SRT。
5. 更改第二场景字幕，仅导致对应字幕/合成任务更新，其他与其无关的原始素材维持可用；修改历史断言时系统提示可能受影响的分镜及产物。
6. Worker 在中途崩溃后重启，可以从数据库重建未完成任务，安全继续或标记需要人工处理；无重复覆盖、无“界面完成而文件不存在”。

## 明确非目标
- 自研或微调基础模型、本地文生视频训练、ComfyUI/Wan/LTX 集群、GPU 购买。
- 实现完整专业 NLE 的所有能力（先保证最小实用多轨时间轴）。
- 以一开始就拥有 100 匹精细标注名马作为门禁；保留全量图鉴，但先做 3 个高质量证据示例和少量审核样例。
- 在没有真实实验结果前宣称原创算法已证明显著更优；或将可用的工具和 API 包装成虚假的自主 Agent。
- 在本轮公开部署、开源私有代码或购买付费 API（除非另行授权）。

## 定义 Done：五个层次都需要检查
- D1 源码真实存在、可构建，配置按文档可复现。
- D2 API 和 DB 迁移正常，原有业务回归通过。
- D3 前端完整交互真实调用后端，不仅模拟 UI。
- D4 有代表性的端到端测试、真实 MP4/字幕/元数据、任务恢复证据。
- D5 研究结果标签明确：模拟/离线/真实服务/人工评审；未验证部分留在风险登记表。

## 低成本准则
普通 CPU 为默认环境；所有可选第三方 AI Provider 需 Feature Flag，断网/无凭据时人工作业、内容管理、素材剪辑、任务持久化和 CPU 导出不失效。研究实验先使用离线模拟器和已清权素材，不产生云端费用。
