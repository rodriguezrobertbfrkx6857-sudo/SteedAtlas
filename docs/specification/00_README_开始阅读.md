## 绝对不变的方向
1. **这是网站工程，不是模型训练工程**。禁止把 GPU、Wan、ComfyUI、微调或云端视频生成列为必需依赖。
2. 首选保留现有 **FastAPI / SQLAlchemy / React 资产 / FFmpeg / 业务数据库 / 图片音视频素材**；迁移而不是无差别推倒重做。
3. Agent 创新集中在 **按需角色调用、证据约束、结构化修改提案、可解释决策、局部修复**；不得拿模拟多 Agent 动画冒充真实执行。
4. 视频工厂必须允许 **仅凭用户素材和模板、在普通 CPU 下输出可播放 MP4**；外部 LLM/TTS/视频 API 均为可选扩展。
5. 复用开源功能，不盲目复制开源项目整站；每一个候选依赖要做许可证、维护、API、兼容性和测试核验。
6. 所有完成状态都要有可检查的代码、自动测试、截图/录屏或可播放文件和日志；不得虚报完成。

## 交付物
- 可构建前端、可启动后端、可迁移数据库、可运行 CPU 视频导出任务；原有功能有回归保障。
- 可信知识结构：Source/Passage/Claim 版本化及可打开的引用；中文实体别名和 BM25 强基线。
- 创作核心：Project/Script/SceneBible/Scene/Asset/Timeline，手动模式可用，可选择 AI 辅助。
- Agent：可按需调度的 Research/Narrative/Director/Review/Repair 能力；每个输出可追踪，且无自我授权。
- 工作流：真实 DAG、持久任务、恢复、依赖失效、分段重试、资产校验。
- 安全修复、测试证据、开源 NOTICE/许可证清单、科研对照实验、回滚文档、最终报告。
