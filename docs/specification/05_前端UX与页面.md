# 前端 UX、页面与可访问性

## 主站结构
- 首页：品牌首屏、精品名马、查史料入口、作品样例、创作 CTA；不把抽卡/商城/视频工厂所有卡片堆在首屏。
- 名马列表：可搜索、可筛选（朝代、地域、文献属性、人物关系），分页/虚拟列表依规模选择。
- 名马详情：头图、别名/时代、事实与文学分类、证据深度、来源 passage 定位、问答、制作故事按钮。
- AI 问答：带可点开文献摘录的行内引用，回答可信度解释、证据不足拒答、对话反馈。
- 创作工作台 Guided：主题 → 剧本 → 分镜 → 素材 → 时间轴 → 预览/导出；可恢复草稿。
- 创作工作台 Expert：任务 DAG、逐节点状态、Agent 决策/提案、影响范围预览、素材校验与日志；两个视图共享真实 API 和 Job。
- 我的作品与用户中心：草稿/进行中/失败/导出完成、收藏、访问权限。
- 管理后台：Source/Passage/Claim 审核、名马编辑、版权状态、作品发布、用户 RBAC、审计。
- 其他已有页面：抽卡/性格/文创等保留兼容，不因主站重构删除旧业务。

## 视觉原则
数字博物馆编辑风格：克制中文文化符号、清晰中文排版、足够留白、统一图标和状态色。不要只靠深色渐变和过度动效“显得高级”。

## 可用性要求
- 320px~大屏响应式；工作台窄屏可以切换分步视图；不能要求手机用户在狭窄画布操作所有节点。
- Loading/Empty/Error/Saved/Unsaved/Conflict/NeedsReview/Retrying/Failed/Done 均有真实状态文案。
- WCAG 2.2 AA 作为设计目标：键盘操作、Focus、对比度、拖拽操作替代方式、字幕、减少运动、图像 alt。
- 历史与文学类别用文本+图标，不仅靠颜色辨认；来源引用跳转到精确段落、原文语言标签。
- 对重要的写入操作使用请求幂等与重复提交保护；UI 不能显示成功直到后端确认。
- 高级 DAG 画布应有屏幕阅读器可访问的节点列表与依赖表。

## 页面级验收清单
1. 首屏 LCP/交互响应量化测量，不预先宣称达标数字；分析 bundle 和大图成本。
2. 名马列表至少验证 100 条已有数据的原样保存和过滤。
3. 刷新编辑器时，已保存的剧本、分镜、素材选择和时间轴保持一致。
4. 浏览器断网 / API 超时 / 版本冲突显示可恢复的错误，不丢失用户输入。
5. 通过真实用户操作从名马页创建工程并导出 MP4，不以静态产品展示动画充数。
6. 旧有功能与 URL 通过兼容路由或迁移重定向尽可能保留；记录任何明确的破坏性变更。
