# 百骑谱 / SteedAtlas：项目摘要

百骑谱是面向历史文化资料查阅与内容创作的工程项目：保留原黑金文化网站，将图鉴、客服问答、受控 Research 工具和视频工作流连接到同一知识访问层。

用户可以浏览 100 项编辑名马档案，从赤兔、乌骓、的卢的问答进入具体文献版本和原文段落。系统区分编辑故事、历史文献记载和文学叙事；机器核对通过只表示原文、位置、版本、哈希与使用策略符合检查，不等于专家审核或史实认证。最新覆盖数字以 `reports/resume-readiness/coverage.json` 为准，不能将目录数量说成全部有独立史料支持。

技术栈为 Python/FastAPI、SQLAlchemy/SQLite、中文繁简规范化与 BM25、原站 React 编译资源加局部 JavaScript 适配，以及 FFmpeg CPU 合成。主站完整 React 原始工程尚未恢复，非默认 TypeScript 草稿不能代表重写了原网站。

自动知识链路通过维基文库官方 API 有界获取，固定修订并保存原始与渲染哈希、段落偏移和许可元数据，支持幂等入库、来源失效、有限刷新和明确标识的离线快照。Wikidata 仅为身份候选适配器；HF/Kaggle 等尚未全面进入正文库，不能称为已完成多源大规模融合。

统一问答采用检索和确定性归属模板，输出精确引文、简短摘要与支持边界；没有实时 LLM 文本综合。Research 使用真实工具执行与规则调度，保留调用结果、预算、异常和清理记录。已加入每用户/全实例采集额度与串行租约，避免普通登录用户无限触发采集。

视频侧复用持久化 DAG、租约、重试、取消与产物检查，执行带来源标签的 CPU 程序化短片。商城测试为沙箱，无真实交易或配送。本轮未公开部署、未付费调用 LLM/Jev，未获得人工历史学金标准；代理检索指标不是历史准确率或生产 SLA。

可核验材料：`RELEASE_ACCEPTANCE.md`、`DEMO_RUNBOOK.md`、Git 提交、JUnit、浏览器报告、真实工具 trace 和本地视频。个人贡献、赛事及奖项须与本人真实经历分别核对，不能将项目能力自动等同于个人独立完成。
